# Orcamentos Brasil

Micro-SaaS multi-tenant para prestadores de serviço criarem, enviarem (PDF, WhatsApp, link público) e acompanharem orçamentos.

- Visão do produto: [docs/visao-do-produto.md](docs/visao-do-produto.md)
- Plano de implementação do MVP: [PLAN.md](PLAN.md)

## Stack

FastAPI + PostgreSQL (backend) · React + Vite + TypeScript + Tailwind + shadcn/ui (frontend) · Docker Compose + Caddy (deploy).
